Terms of Service — Internal Clipping Pipeline API Client

Last updated: October 18, 2026

Scope

This client is an internal tool operated by Benjamin Anderson ("the operator") for the operator's own YouTube channels only. It is not offered to the public, has no third-party users, and creates no accounts for anyone else.

Permitted use

The client is used to upload original-transformed Shorts — edited from footage the operator is licensed to clip through Whop Content Rewards campaigns, with added headers, timed captions, and editorial structure — to the operator's own linked channels, and to submit the resulting post links to those campaigns for review.

Commitments

  • One Google Cloud project serves the whole channel fleet; multiple projects will not be created to multiply API quota.
  • No public API uploads will be attempted before the YouTube API compliance audit clears; until then, posting uses YouTube's own web interface at ramp volume.
  • Content uploaded complies with YouTube's Terms of Service, Community Guidelines, and the YouTube API Services Terms and Developer Policies, including the reused-content rules: one moment runs on one channel only.
  • API access will not be sold, shared, or transferred.

Limitation

The client is provided for the operator's internal use as-is, without warranty. These terms may be updated; the current version will remain available at this URL.
