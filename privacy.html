Privacy Policy — Internal Clipping Pipeline API Client

Last updated: October 18, 2026

Who operates this client

This API client is an internal tool operated by Benjamin Anderson ("the operator"). It is not a public service and has no users other than the operator.

What data the client accesses

Through the YouTube Data API v3, using the operator's own Google account and OAuth authorisation, the client accesses only the operator's own channels:

  • Channel and video identifiers for the operator's own channels
  • Upload status and processing state for videos the client uploads
  • Basic channel status information needed to confirm posting eligibility

The client does not access data belonging to any other YouTube user, and it has no third-party users whose data could be collected.

How the data is used

Authorised data is used solely to (a) upload Shorts to the operator's own channels, (b) confirm upload/posting status, and (c) keep local outcome records (views, earnings, rejections) used to operate and improve the clipping pipeline.

Storage, retention, and sharing

  • Authorised data is stored locally on the operator's own systems.
  • Stored authorised data is refreshed or deleted within 30 days, consistent with the YouTube API Services Developer Policies.
  • No API data is sold, rented, shared with third parties, or used for advertising.

Revocation and deletion

The operator can revoke the client's access at any time from the Google account's third-party access settings. On request or on revocation, locally stored authorised data is deleted.
